# T04 controlled basic-color set

`basic11_controlled.csv` is a ChromaLens-authored deterministic test set with
one deliberately non-anchor sRGB patch for each supported basic family. It is
not a claim of real-world color-name accuracy and contains no personal data,
third-party image, or model output.

The expected English vocabulary and Vietnamese labels match
`assets/color_names/README.md`. RGB samples stay below the configured highlight
clipping threshold where they are used by extraction tests. T09 must replace
this smoke/contract evidence with a declared, broader evaluation protocol
covering physical samples, cameras, displays, and lighting conditions.

license.
