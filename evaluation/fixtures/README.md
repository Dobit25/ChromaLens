# T09 Fixture Registry

`test_cases.csv` is the frozen protocol 1.0.0 case registry. It defines case
slots and expected observations; it does not assert that unacquired footage
exists or that a result passed.

## Asset status at Gate 0

- `AVAILABLE_TRACKED`: repository fixture exists and already has provenance.
- `GENERATED_AT_RUN`: deterministic input is generated by repository code.
- `TO_BE_ACQUIRED`: the case is locked but cannot run until a compliant input
  and manifest exist under ignored `artifacts/t09/`.
- `INLINE_SYNTHETIC`: RGB values/settings are fully identified in the row and
  require no media file.

Acquiring an asset does not change its case ID. The result points to the exact
manifest entry and checksum. A different asset is a separate result execution,
not an undocumented replacement.

## Column rules

- `case_id`: unique stable identifier.
- `workstream`: one frozen ownership key.
- `category`: evaluation area.
- `fixture_id`: stable logical fixture or pair name.
- `asset_ref`: tracked path, ignored path template, inline definition, or
  deterministic generator reference.
- `gate_asset_status`: status when protocol 1.0.0 was frozen.
- `input_kind`: image, video, synthetic color pair, generated stream, or
  human-readable baseline record.
- `lighting`, `motion`, `cvd_profile`, `severity`: exact condition or `NA`.
- `expected_observation`: falsifiable qualitative/contract expectation.
- `required_metrics`: semicolon-separated names from the metric registry.
- `provenance_class`, `consent_requirement`, `license_requirement`: minimum
  evidence needed before use.
- `owner`: workstream key that records the result.

Rows with `TO_BE_ACQUIRED` are `NOT_RUN` until their manifests pass provenance,
consent, license, and checksum checks. Do not substitute private footage or
download media without a rights review.
