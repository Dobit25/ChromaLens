## Procedure

The current default webcam pipeline was requested at 480x360. The camera
delivered 640x360. The run was headless, with 15 seconds warm-up and a fresh
60-second measurement window. The wrapper saved terminal telemetry only; no
frame was stored or uploaded.

This is a Gate 0 snapshot, not the final T15 acceptance benchmark. T15 remains
locked to 300 seconds and requires both GUI and headless evidence.
